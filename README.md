# Photo to Figure Memory Card

An original Codex skill that turns each supplied travel or figure photo into two companion outputs:

1. a loose, source-faithful figure sketch;
2. a 3:2 horizontal memory card with one main illustration, six sticker fragments, and three English keywords.

The `assets/examples/` folder contains generated artwork showing the intended sketch-to-card progression. It intentionally contains no original photographs.

## Use

Install the skill folder into your Codex skills directory, then attach one or more photos and ask for:

> Use `$photo-to-figure-memory-card` and return both the sketch version and the final memory card for each photo.

Generated files should be saved to `D:\小红书旅游` when that destination is available.
